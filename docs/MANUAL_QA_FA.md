# راهنمای بازبینی دستی داده‌های مکالمه

این بازبینی روی صوت‌های آرشیوی موجود انجام می‌شود و به ضبط صدای جدید نیاز
ندارد. هدف آن سنجش کیفیت تفکیک گوینده، انتساب کپشن و برچسب هم‌پوشانی است؛
این فرایند به‌تنهایی مجوز استفاده از داده را تأیید نمی‌کند.

## ساخت نمونه

پس از پایان تفکیک گویندگان:

```bash
.venv/bin/python -m thesis_s2s.cli sample-conversation-qa
```

فایل
`data/processed/manifests/conversation_manual_qa.csv`
به‌صورت قطعی از هر ترکیب موجودِ کانال و نتیجه خودکار
(`automatic_pass` یا `automatic_reject`) نمونه می‌گیرد. مقدار پیش‌فرض پنج
پنجره از هر طبقه است. اندازه نهایی نمونه و آستانه پذیرش باید به تأیید استاد
راهنما برسد.

## روش بررسی هر ردیف

مسیر صوت در ستون `audio_filepath` آمده است. فایل را فقط در محیط داخلی مجاز
پخش کنید و این موارد را بررسی کنید:

| ستون | مقدار | پرسش |
|---|---|---|
| `speaker_count_correct` | `yes` / `no` | آیا تعداد گویندگان تشخیص‌داده‌شده درست است؟ |
| `speaker_assignment_correct` | `yes` / `no` | آیا بخش‌های گفتار به گوینده درست نسبت داده شده‌اند؟ |
| `caption_acceptable` | `yes` / `no` | آیا کپشن برای محتوای صوت قابل قبول است؟ |
| `overlap_annotation_correct` | `yes` / `no` | آیا هم‌پوشانی/قطع گفتار درست تشخیص داده شده است؟ |
| `review_status` | `pass` / `fail` | نتیجه کلی بازبینی |
| `reviewer_id` | شناسه مستعار | شناسه ثابت بازبین؛ نام واقعی لازم نیست |
| `notes` | متن اختیاری | علت رد یا نکته کیفی |

برای پذیرش یک ردیف، `review_status=pass`، هر چهار کنترل برابر `yes` و
`reviewer_id` غیرخالی لازم است. هر پاسخ ناقص یا منفی به‌صورت بسته و محافظه‌کار
رد می‌شود. ردیف‌های `automatic_reject` نیز باید بررسی شوند تا خطای رد خودکار
قابل مشاهده باشد؛ بازبینی دستی آن‌ها به‌طور خودکار داده را وارد آموزش نمی‌کند.

## اعمال تصمیم‌ها و ممیزی

```bash
.venv/bin/python -m thesis_s2s.cli apply-conversation-qa
.venv/bin/python -m thesis_s2s.cli audit-diarized-episodes \
  --manifest data/processed/manifests/conversation_episode_windows_reviewed.jsonl
```

دستور اول منیفست خودکار را تغییر نمی‌دهد و یک منیفست بازبینی‌شده و گزارش
`results/manual_qa_report.json` می‌سازد. ممیزی فقط زمانی پوشش نمونه را قبول
می‌کند که تمام طبقه‌های موجود بازبینی شده باشند.

فایل صوت، CSV بازبینی و منیفست‌های دارای مسیر داخلی نباید در مخزن عمومی قرار
گیرند. تأیید کتبی حقوق استفاده از آرشیو، تصمیمی جداگانه و الزامی است؛ روش ثبت
آن در `RIGHTS_REVIEW_FA.md` آمده است.
